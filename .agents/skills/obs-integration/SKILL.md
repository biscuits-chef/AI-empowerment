# OBS 集成

## 工作流

1. 确认提供方、区域、端点、Bucket、数据驻留、对象大小分布、保留、加密、访问和生命周期要求。
2. 将华为 SDK 限制在 `adapter.out.storage` 内，通过 `ObjectStoragePort` 暴露符合业务语义的操作。
3. 生成服务端控制的 Key，校验大小以及声明/探测到的内容，流式处理字节并限制内存/并发。
4. 定义校验和、幂等性、覆盖/版本控制、分段阈值、上传中止及重试/超时行为。
5. 使用私有 Bucket、最小权限 IAM、TLS、密钥管理系统注入、按需启用 KMS，并在采用预签名访问时缩短有效期。
6. 对 OBS 与 GoldenDB 之间的每种部分失败建模。简单流程使用补偿；保证要求更高时使用 Outbox/Saga 与对账。
7. 为延迟、状态类别、重试、字节数、分段清理、补偿和孤儿对象对账添加安全指标/日志；绝不记录对象内容或凭据。
8. 使用可控测试替身验证适配器契约和失败路径，再在非生产 OBS 中验证权限、加密、大对象、限流、网络故障与清理。

## 完成条件

报告 API/端口变更、安全状态、部分失败矩阵、清理责任人、测试证据和仅可在环境中完成的检查。
