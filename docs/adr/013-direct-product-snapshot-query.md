# ADR-013：直接查询产品主题快照表并使用元数据约束查询计划

- 状态：已接受，物理主键部分已被 ADR-015 取代
- 日期：2026-09-08
- 取代范围：ADR-008 中的产品语义视图、单一投资经理口径和仅支持 `PRODUCT_LOOKUP` 的产品查询决策

## 背景

数据中台已经提供产品主题数据集及配套的数据集注册、字段注册和枚举注册。产品业务数据将同步到本系统 GoldenDB；当前只有一张产品物理表。项目需要先支持查询指定产品投资经理、产品经理，以及查询今日命中定开基准日或产品到期日的产品。

## 决策

1. 产品 SQL 最终直接查询 `dws_product_info_d`，不再依赖 `biz_semantic_product_v`。
2. 数据集注册、字段注册和枚举注册是模型理解查询范围的元数据；模型只产生结构化意图、字段和筛选条件，不能输出直接执行的 SQL。
3. Flyway 创建 `dws_product_info_d` 空表、业务唯一键和查询索引；数据中台负责同步每日全量业务快照，物理主键由 ADR-015 约束。
4. `PRDC_CD + DT` 构成快照唯一键。查询先使用 `MAX(DT) <= 业务日期` 选择最新有效分区。
5. `PROD_MAT_DT`、`PERI_OPEN_BASE_DT` 和 `DT` 均为 `VARCHAR(10)`，唯一允许格式为 `yyyy-MM-dd`；同步任务必须同时校验格式和真实日期有效性。
6. 产品代码、名称、简称和全称用于产品解析；多候选必须追问，不得静默选择第一条。
7. 投资经理查询同时返回 `INVS_MNGR_NM` 监管口径和 `PRDC_INVS_MNGR` 产品部口径。
8. 日期列表计划同时查询 `PERI_OPEN_BASE_DT` 和 `PROD_MAT_DT`，并分别返回命中标志。
9. 产品查询只允许预批准 MyBatis Statement 和 `#{}` 参数绑定。当前单表场景不执行自由 Join、动态表名或动态列名。

## 后果

- 本地和后续 GoldenDB 环境可以直接接收数据中台的产品快照。
- 三个首批问题具有确定性查询计划和可审查 SQL。
- 日期使用字符串类型要求同步链路执行严格质量校验。
- 产品表当前没有行级用户权限字段；生产启用前必须由数据负责人确认全员可见范围或提供可进入 SQL 的权限方案。
- 交易查询暂时保留原兼容路径，不属于本次产品表迁移范围。

## 验证

- Mapper 测试覆盖最新分区、未来分区排除、代码/名称/简称/全称解析、两种投资经理口径，以及两个日期条件的单独和同时命中。
- 领域测试覆盖三个稳定意图、字段白名单、日期列表计划和固定 Statement 编译。
- 完整运行 `mvn -B -ntp clean verify`。
- 生产启用前在真实 GoldenDB 验证迁移、索引、`EXPLAIN`、字符排序规则、连接预算和数据权限。
